Desktop (M5.10): accessibility pass + Playwright-electron end-to-end tests.

- **Accessibility**: the screen switcher is now a proper ARIA `tablist` (roving
  tabindex, arrow/Home/End keys, `tab`/`tabpanel` wiring); every control has an
  accessible name (labeled Gates waive/evidence inputs, the AI task select, repo
  list items with `aria-current`); visible focus rings on the custom tab/nav
  buttons; async results announce via `aria-live`; `prefers-reduced-motion` disables
  spinners/transitions; and the color palette was tuned so text clears WCAG AA
  contrast (darker primary buttons, lighter muted/dim text) — a light theme palette
  was also added for the Settings theme toggle.
- **End-to-end**: a Playwright-electron harness launches the built app with an
  isolated userData dir and runs the sign-in (canned device flow via a test-only
  seam), audit, and waive flows, plus axe-core checks on every screen (fails on any
  serious/critical violation). Runs in CI on Ubuntu under xvfb as a required check.
